# example-2027 — 가상 예시 사이트

이 폴더는 템플릿의 모든 기능을 보여 주는 **가상** 행사입니다. 사람·기관·일정·이메일은 모두 지어낸 것입니다.

- `conference.json` — 작성 예시. 새 행사는 `python3 scripts/new_site.py <slug> --from sites/example-2027` 로 복사해 시작합니다.
- `assets/` — 자리표시자 PDF 와 안내문
- `index.html` — 빌드 결과(미리보기용). 더블클릭해 열 수 있습니다. 수식과 지도는 인터넷 연결이 있어야 표시됩니다.

실제 행사의 원본 폴더는 이 공개 저장소에 넣지 말고(평문 이메일이 들어갑니다) 본인의 비공개 저장소나 컴퓨터에 두세요.
