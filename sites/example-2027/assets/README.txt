이 폴더에는 홈페이지에서 쓰는 파일을 넣습니다.

- hero.jpg          대표 사진 (가로 1600px 이상 권장). conference.json 의 hero.image 에 "assets/hero.jpg"
- logo.svg / .png   기관 로고 — 사용 권한이 있는 파일만. conference.json 의 logo.src 에 경로
- poster.pdf        포스터 → downloads
- slides/<id>.pdf   발표자료 → speakers[].slides
- group.jpg         단체사진 → gallery

여기 있는 poster.pdf 와 slides/gildong-hong.pdf 는 글자 한 줄만 있는 자리표시자입니다.
