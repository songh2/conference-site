# OpenDesign 디자인 규칙 (웹 도구의 "AI 디자인" 기능이 씀)

웹 도구의 **AI 디자인 시안(포스터)** 과 **AI 배색·첫 화면 그림 제안(홈페이지)** 은 AI(팩트챗 등 본인 키)에게
아래 규칙을 함께 보내, OpenDesign 이 AI 에이전트에게 주는 것과 같은 디자인 기준으로 결과를 만들게 합니다.

| 파일 | 내용 |
|---|---|
| `craft/typography.md` | 글자 크기 단계, 행간(한글·중국어 등 CJK 는 제목도 1.3 이상), 자간, 글꼴 2종 이내 |
| `craft/typography-hierarchy.md` | 시선이 들어가는 곳 하나, 단계 사이의 대비, 정보 흐름 |
| `craft/color.md` | 배색 구조(중성색 70–90%, 강조색 1개), 강조색 남용 금지, 대비 기준 |
| `craft/anti-ai-slop.md` | "AI 가 만든 티" 나는 패턴 금지(흔한 보라 계열, 이모지 아이콘, 지어낸 수치·문구 등) |
