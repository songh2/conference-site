# 웹 도구로 만들기 (설치 없음)

> **주소: https://songh2.github.io/conference-site/**
> 브라우저에서 칸을 채우면 오른쪽에 홈페이지가 바로 보이고, 다 되면 ZIP 을 받아 GitHub 에 올리면 끝입니다.
> 파이썬·AI 도우미·프로그램 설치가 필요 없습니다. 서울대학교 공식 서비스가 아닌 개인 프로젝트입니다.

## 1. 무엇이 되나

| 할 수 있는 것 | 어디서 |
|---|---|
| 한·영 홈페이지 만들기 (행사명, 일시, 장소, 프로그램, 연사·초록·수식, 위원회, 문의처, 공지, 자료, 사진, 후원) | 각 탭 |
| 실시간 미리보기 (PC·휴대폰 폭) | 오른쪽 |
| 서울대 단과대학 배색 17종 | 디자인 |
| 홈페이지 안 사전등록 양식 + 구글 시트 접수 스크립트 | 등록 |
| 인쇄 포스터 4종 (A1~A4, QR 코드) · OpenDesign 브리프 | 포스터 |
| **홈페이지 주소로 샘플(시안) 포스터** — 덜 채워진 홈페이지도 가능 | 포스터 탭 맨 위 |
| 공개된 홈페이지 주소에서 불러와 이어서 고치기 | 시작하기 |
| **AI 디자인 시안** — OpenDesign 디자인 규칙으로 새 포스터 시안, 요청 문장으로 계속 고치기 (크레딧 사용) | 포스터 탭 아래쪽 |
| **AI 배색·첫 화면 그림 제안** — 홈페이지 색·글꼴·배경 그림 (크레딧 사용) | 디자인 탭 아래쪽 |
| 공문·포스터에서 자동 채우기 (본인 API 키) | 시작하기 |
| 검사, 배포용 ZIP, 원본 저장 | 검사·내려받기 |
| GitHub Pages 올리는 순서 | GitHub에 올리기 |

홈페이지·검사·포스터·등록 스크립트는 저장소의 `scripts/*.py` 를 **브라우저 안에서 그대로 실행**해 만듭니다(Pyodide). 그래서 AI 도우미나 컴퓨터에서 `python3 scripts/build.py` 로 만든 것과 결과가 같습니다(자동 시험으로 확인).

## 2. 처음 쓰기 (10~20분)

1. **Chrome 이나 Edge** 로 위 주소를 엽니다. 처음 한 번은 오른쪽 위가 "◌ 파이썬 엔진 내려받는 중…" 으로 보입니다. 엔진은 약 12MB(압축 전 기준)이고 인터넷 속도에 따라 10초~1분 걸립니다. "● 준비됨" 이 되면 시작합니다. 다음부터는 브라우저에 저장된 사본을 쓰므로 빨라집니다.
2. **시작하기** 에서 고릅니다.
   - 새로 만들기: 빈 양식
   - 예시로 둘러보기: 모든 칸이 채워진 가상 행사 (처음이면 이것부터 보세요)
   - 불러오기: 예전에 보관한 `conference.json`, 또는 이 도구로 받은 ZIP
3. 왼쪽 단계 순서대로 채웁니다. 한국어·영어 칸이 나란히 있고, 영어를 비우면 영어 화면에도 한국어가 나옵니다.
   - **자료에 없는 내용은 비워 두세요.** 비운 칸의 부분은 홈페이지에서 자동으로 숨겨집니다.
   - 사진·PDF 는 각 칸의 **파일 올리기** 로 넣습니다. 사진은 본인 동의를 받은 것, 로고는 사용 권한이 있는 것만.
4. **검사·내려받기** 탭에서 빨간 오류가 없으면 **배포용 ZIP 받기** 를 누릅니다. 노란 경고는 "확인 필요 목록"입니다(대부분 영문이 비었다는 안내).
5. **원본 저장** 도 눌러 `○○-conference.json` 을 학과 공유 폴더 등에 보관하세요. 나중에 고칠 때 이 파일을 불러옵니다. 이 파일에는 이메일이 평문으로 들어 있으니 **공개 저장소에는 올리지 않습니다.**
6. **GitHub에 올리기** 탭의 순서대로 올립니다(처음 한 번 10분). 더 자세한 설명: [GitHub Pages 매뉴얼](manual-github-pages.md).

## 3. 자료에서 자동으로 채우기 (AI, 선택)

공문·포스터(PDF·그림)·한글(HWPX)·워드(DOCX)·텍스트 파일을 올리면 AI 가 읽어 칸을 채웁니다. **본인의 API 키가 필요하고, 사용료는 키를 만든 계정에서 나갑니다.**

**어떤 키를 쓰나요?**

| 누구 | 쓸 키 | 웹 도구에서 고를 "AI 서비스" |
|---|---|---|
| **서울대 구성원** | 학교가 제공하는 **팩트챗**에서 발급받은 키 | 팩트챗 (서울대 구성원) |
| **개인적으로 LLM 서비스를 쓰는 분** | 그 서비스에서 받은 키(사용료 본인 부담) | OpenAI (개인 계정), 또는 직접 입력 |

학교 ChatGPT Edu 에서는 API 키 발급 안내를 찾지 못했습니다(2026-10-27, 공개 자료 기준). 서울대 구성원은 팩트챗 키를 쓰세요.

| AI 서비스 | 주소(자동 입력) | 그림(포스터) 읽기 |
|---|---|---|
| 팩트챗 (서울대 구성원) | `https://api.baze.co/v1/gateway` (서울대 개발자 문서의 주소) | Claude 계열 모델(`claude-…`)만. 다른 모델은 글자만 |
| OpenAI (개인 계정) | `https://api.openai.com/v1` | 됨 |
| 직접 입력 (다른 서비스) | 그 서비스의 OpenAI 호환 주소 | 서비스에 따라 다름 |

- **키 만들기**: 아래 「API 키 발급 방법」을 보세요. 웹 도구 화면의 "🔑 어떤 키를 쓰나요? · 발급·보관 방법"을 펼쳐도 같은 내용이 나옵니다.
- **모델 고르기**: 키를 넣고 "모델 목록 불러오기"를 누르면 쓸 수 있는 모델이 나옵니다. 그림으로만 된 포스터(글자를 복사할 수 없는 PDF)는 그림을 읽는 모델이 필요합니다. 팩트챗이라면 `claude-…` 모델을 고르세요(서울대 문서의 Messages API 항목에 그림 입력 "지원"으로 적혀 있음).
- **채우는 방식**: "자료 내용으로 새로 채우기"(지금 고른 테마·로고·포스터 설정은 그대로 둠) 또는 "지금 비어 있는 칸만 채우기".
- **결과 확인**: 적용하기 전에 요약표와 "확인 필요" 목록이 나옵니다. **AI 는 틀릴 수 있습니다.** 적용한 뒤 각 탭에서 원문과 한 줄씩 대조하세요. 자료에 없는 것은 지어내지 말고 비워 두도록 지시해 두었지만, 결과를 보장하지는 않습니다.
- **개인정보**: 올린 자료는 고른 AI 서비스로 전송됩니다. 참가자 명단·주민등록번호 같은 개인정보 파일은 올리지 마세요. 개인 계정의 LLM 서비스로 학교 업무 자료를 보낼 때는 학교 정책도 확인하세요.
- 예전 한글 형식(.hwp)은 읽지 못합니다. 한글에서 "다른 이름으로 저장 → PDF 또는 HWPX" 로 저장해 올리세요. PDF 는 앞 8쪽까지, 그림은 12장까지 읽습니다.

### API 키 발급 방법

> 팩트챗·OpenAI 모두 **키 전체는 만들 때 한 번만** 보여 줍니다. 발급 창을 닫기 전에 복사해 **따로 보관**하세요(아래 「발급받은 키 보관」).
> 아래 내용은 2026-10-27 에 각 서비스의 공식 문서로 확인했습니다. 화면 개편으로 메뉴·버튼 이름이 바뀔 수 있습니다.

**① 서울대 구성원: 팩트챗** — 출처: 서울대 팩트챗 개발자 문서 [개요](https://docs.factchat.kr/docs/snu/api-gateway/getting-started/overview), [인증(API 키)](https://docs.factchat.kr/docs/snu/api-gateway/getting-started/authentication)

1. 학교가 제공하는 팩트챗 웹사이트에 로그인합니다.
2. 화면 왼쪽 아래의 **API Gateway** 버튼을 누릅니다.
3. **API 키 생성** 버튼을 눌러 키를 만듭니다. 이름을 붙일 수 있으면 `conference-site 웹도구` 처럼 용도를 적습니다.
4. 만들어진 키를 **바로 복사해 따로 보관**합니다. 문서: "생성된 키는 다시 조회할 수 없습니다."
5. 웹 도구에서 AI 서비스를 "팩트챗 (서울대 구성원)"으로 두고 키를 붙여 넣은 뒤 **모델 목록 불러오기** 로 확인합니다. 주소 칸에는 `https://api.baze.co/v1/gateway` 가 자동으로 들어갑니다.

- 사용료는 키를 만든 계정의 크레딧에서 차감됩니다.
- 키 삭제(해지)는 같은 **API Gateway** 화면에서 언제든 할 수 있고, 해지는 되돌릴 수 없습니다. 노출되었다면 즉시 해지하고 새 키를 발급하라고 안내되어 있습니다.
- 서울대 문서에 적힌 제한: 구성원 한 명당 60초에 120회 요청, 요청 한 번에 25MB(넘으면 413 오류). 이 웹 도구는 그림을 줄여 보내므로 보통은 넘지 않습니다.
- 확인하지 못한 것: 문서에는 로그인할 곳이 "서울대학교 웹사이트"로만 적혀 있어 정확한 접속 주소는 학교 안내를 따르세요. 키에 이름·만료일을 붙일 수 있는지도 문서에 없습니다.

**② 개인적으로 쓰는 LLM 서비스: 예) OpenAI** — 출처: OpenAI 도움말 [API 키 찾기](https://help.openai.com/en/articles/4936850-where-do-i-find-my-openai-api-key), [API 키 안전 수칙](https://help.openai.com/en/articles/5112595-best-practices-for-api-key-safety), [개발자 빠른 시작](https://developers.openai.com/api/docs/quickstart)

1. [platform.openai.com](https://platform.openai.com/) (개발자 플랫폼)에 로그인합니다. 계정이 없으면 가입합니다.
2. API 사용료는 개발자 플랫폼의 [결제(Billing)](https://platform.openai.com/account/billing/overview) 화면에서 충전한 크레딧으로 냅니다(본인 부담).
3. (권장) 이 도구용 프로젝트를 따로 두고, 프로젝트의 **Limits** 에서 **Set Budget** 으로 월 사용 한도를 정합니다. OpenAI 는 알림만으로는 사용이 멈추지 않으므로 한도를 정하라고 권합니다.
4. [API keys](https://platform.openai.com/api-keys) 화면에서 **Create new secret key** → 이름(예: `conference-site 웹도구`)을 적고 만듭니다. OpenAI 는 만료일이 있는 키를 만들고 주기적으로 바꾸라고 권합니다.
5. 나온 키를 **바로 복사해 따로 보관**합니다. 도움말: 전체 키는 만들 때 한 번만 보여 줍니다.
6. 웹 도구에서 AI 서비스를 "OpenAI (개인 계정)"로 바꾸고 키를 붙여 넣습니다.

- 키 삭제는 API keys 화면에서 키 옆의 휴지통 아이콘을 누릅니다(지운 키는 바로 쓸 수 없게 됨). 사용 내역은 Usage 화면에서 봅니다.
- 3·4번의 메뉴 이름(Limits, Set Budget, Create new secret key)은 OpenAI 공식 문서가 아닌 대학 지원 문서(2026-06)에서 확인했습니다.
- **그 밖의 서비스**: "직접 입력"을 고르고, 그 서비스 개발자 문서에 있는 OpenAI 호환 주소(`https://…`)·키·모델 이름을 넣습니다. 공식 주소(팩트챗·OpenAI)가 아니면 보내기 전에 확인창이 한 번 더 뜹니다.

### 발급받은 키 보관

- 이 웹 도구는 키를 저장하지 않습니다(새로고침하면 사라짐). 쓸 때마다 보관한 곳에서 꺼내 붙여 넣습니다.
- **보관 장소**: 비밀번호 관리자 프로그램의 보안 메모(예: Bitwarden, 1Password)가 가장 좋습니다. 어렵다면 개인 PC 안의 암호를 건 파일에 둡니다. 키 이름·만든 날·어디에 썼는지를 함께 적어 두면, 유출이 의심될 때 어느 키를 지울지 바로 알 수 있습니다.
- **두면 안 되는 곳**: 행사 정보 입력 칸·`conference.json`·GitHub 저장소, 학과 공유 폴더, 이메일·메신저(나에게 보내기 포함), 화면 캡처, 모니터에 붙인 메모지.
- **잃어버리면**: 다시 볼 수 없으니 발급한 곳에서 그 키를 삭제하고 새로 발급합니다.

### API 키 안전 수칙 (꼭 읽어 주세요)

> **API 키의 관리와 사용 책임은 사용자 본인에게 있습니다.** 키가 새면 다른 사람이 키 주인의 크레딧(사용료)을 쓸 수 있으니 각별히 유의하세요.

1. **이 웹 도구용 키를 따로 새로 발급받으세요.** 평소 다른 일에 쓰는 키를 넣지 않습니다. 전용 키라면 유출이 의심될 때 발급한 곳(팩트챗·OpenAI 관리 화면)에서 **그 키만 바로 삭제**해도 다른 일에는 지장이 없습니다. 키 이름을 `conference-site 웹도구` 처럼 붙여 두면 찾기 쉽습니다. 발급한 곳에서 사용 한도를 정할 수 있다면 낮게 정해 두세요(서비스마다 기능이 다르며, 팩트챗의 한도 기능은 확인하지 못했습니다).
2. **화면에는 가려져 보입니다.** 키 칸은 `••••••` 로 표시됩니다. 빈칸·오탈자가 걱정되면 옆의 **보기** 버튼을 누르세요. 키가 보이고, **15초 뒤 자동으로 다시 가려집니다**(바로 가리려면 **숨기기**). 키 칸 아래에는 키 전체를 보이지 않고 확인할 수 있는 안내가 나옵니다.
   - `입력됨: sk-t…WXYZ (28자)` → 앞 4자·끝 4자와 길이. 발급 화면의 키와 비교해 보세요.
   - `키가 비어 있습니다` / `키 중간에 빈칸이나 줄바꿈이 있습니다` / `한글이나 특수 기호가 섞여 있습니다` / `너무 짧습니다` → 다시 복사해 붙여 넣으세요. 앞뒤 빈칸은 자동으로 지웁니다.
3. **기본은 저장하지 않습니다.** 키는 이 화면(메모리)에만 있고, 탭을 옮겨 다녀도 남지만 **새로고침하거나 창을 닫으면 사라집니다**. 브라우저 저장소·원본 저장 파일·배포용 ZIP·저장소 어디에도 들어가지 않습니다(자동 시험으로 확인).
4. **"이 브라우저에 키 기억"은 권장하지 않습니다.** 켜려고 하면 경고창이 한 번 더 뜹니다. 켜면 이 컴퓨터의 브라우저(localStorage)에 남아, 이 컴퓨터를 쓰는 다른 사람도 쓸 수 있고, 같은 `songh2.github.io` 주소 아래의 다른 페이지도 읽을 수 있습니다(GitHub Pages 기본 주소에서는 한 계정의 모든 페이지가 같은 `계정이름.github.io` 를 씁니다). **공용 PC 에서는 절대 켜지 말고**, 개인 PC 라도 다 쓰면 **키 지우기** 를 누르세요.
5. **보내는 곳을 확인합니다.** 키와 자료는 "주소" 칸의 AI 서비스로만 보냅니다(이 도구에는 서버가 없습니다). `https://` 가 아닌 주소는 막고, 공식 주소(팩트챗 `api.baze.co`·`factchat-cloud.mindlogic.ai`, OpenAI `api.openai.com`)가 아니면 보내기 전에 "공식 주소가 아닙니다" 확인창을 띄웁니다. **누가 알려 준 낯선 주소를 넣지 마세요.**
6. **다 쓴 뒤**: 키 지우기 → (자주 쓰지 않는다면) 발급한 곳에서 그 키를 삭제. "키 지우기"는 이 화면의 키만 지울 뿐, 발급한 곳의 키 자체는 그곳에서 삭제해야 합니다.
7. **유출이 의심되면** (공용 PC 에 기억시켜 둔 채 자리를 떴다, 화면·메일·메신저에 키를 붙여 넣었다 등): 곧바로 발급한 곳에서 그 키를 **삭제(폐기)** → 사용 내역에서 모르는 사용이 있는지 확인 → 필요하면 새 키를 발급합니다. 기관이 지원하는 키라면 관리 부서에도 알립니다.

## 3-1. 홈페이지 주소로 샘플 포스터 (AI 없이도 됨)

1. **포스터** 탭 맨 위 "홈페이지 주소로 샘플 포스터 만들기" 칸에 공개된 홈페이지 주소를 넣습니다(예: `https://계정이름.github.io/ntc2027/`).
2. **가져와서 샘플 포스터 만들기** 를 누릅니다. 작업 중인 내용이 있으면 바꿔도 되는지 먼저 묻습니다(필요하면 취소하고 "원본 저장" 먼저).
3. 잠시 뒤 아래에 샘플 포스터가 나옵니다. 빈 칸은 "미정", 오른쪽 위에 "시안 · 확정 전" 표시가 붙고, 무엇이 비었는지 노란 경고로 알려 줍니다.
4. 빈 칸을 채우고 싶으면 각 탭에서 고친 뒤 다시 **포스터 만들기**. 확정본은 "샘플(시안)로 만들기" 체크를 끄고 만듭니다.

- **이 도구로 만든 홈페이지**는 함께 공개된 `conference.json` 과 사진·PDF 를 그대로 가져오므로 **AI·API 키가 필요 없습니다.**
- **다른 홈페이지**는 페이지 글을 AI 가 읽어 정리합니다. **시작하기** 탭에 API 키(서울대 구성원은 팩트챗)를 먼저 넣으세요. 키가 없으면 그렇게 안내합니다. AI 는 틀릴 수 있으니 결과를 원래 홈페이지와 대조하세요.
- 다른 사이트에서 읽기를 막은 홈페이지(브라우저 보안 규칙 CORS)는 읽을 수 없습니다. 그 홈페이지를 Ctrl+P → "PDF로 저장" 해서 시작하기 탭의 "자료에서 채우기"에 올리세요.
- 시작하기 탭의 "공개된 홈페이지 주소에서 불러오기"는 같은 방법으로 내용만 불러옵니다(포스터는 만들지 않음). 가져온 것은 공개본이라 이메일이 난독화되어 있으니, 홈페이지를 고칠 때는 보관한 원본이 더 좋습니다.

## 3-2. AI 디자인 (OpenDesign 방식, 크레딧 사용)

"시작하기" 탭에 API 키(서울대 구성원은 팩트챗)를 넣은 뒤 씁니다. 누를 때마다 크레딧이 들고, 화면에 사용한 토큰 양이 나옵니다. 더 정교한 결과를 원하면 "시작하기" 탭에서 `claude-opus-…` 같은 상위 모델을 고르세요(크레딧이 더 듭니다).

**포스터 시안** (포스터 탭 아래쪽 "AI 디자인 시안")
1. 디자인 방향·크기·언어를 고르고 추가 요청을 적은 뒤 **AI 시안 만들기** (1~3분).
2. 마음에 안 들면 "이 시안을 고치기" 칸에 바꿀 점을 적고 **이 시안을 고쳐 달라고 하기**, 또는 **같은 방향으로 다른 시안**.
3. **새 창에서 열기** → Ctrl+P → "PDF로 저장"(여백 없음·배경 그래픽 켜기), 또는 **HTML 파일로 받기**. 시안은 새로고침하면 사라집니다.
- 노란 경고 = 행사 정보에서 찾지 못한 글(AI 가 지어냈을 수 있음), 빨간 경고 = 행사명·일시·장소 빠짐. 인쇄 전에 꼭 대조하세요.

**홈페이지 배색·첫 화면 그림** (디자인 탭 아래쪽 "AI 배색·첫 화면 그림 제안")
1. 분위기를 고르고(필요하면 "자연과학대학 색은 유지하면서 더 산뜻하게" 같은 추가 요청) **AI 제안 받기**.
2. 색 견본·첫 화면 모습과 **글자 대비 검사 결과**를 보고 **적용하기**. 오른쪽 미리보기에 바로 반영됩니다.
3. 마음에 들지 않으면 **되돌리기**. 첫 화면에 사진이 이미 있으면 기본으로는 사진을 바꾸지 않습니다(체크하면 AI 그림으로 바꿈).
- 바뀌는 것은 색 12가지·제목 글꼴(명조/고딕)·모서리 둥글기·첫 화면 배경 그림(`assets/hero-ai.svg`)뿐이고, 등록 양식·한영 전환·이메일 보호 같은 기능은 그대로입니다. 결과는 conference.json 의 `theme` 값으로 저장되어 배포 ZIP·포스터에 함께 쓰입니다.

**팩트챗 API 가 쓰이는 때 (정리)**: 자료에서 채우기, 모델 목록 불러오기, 이 도구로 만들지 않은 홈페이지 주소로 불러오기, AI 디자인 시안·수정, AI 배색 제안. 나머지(입력, 미리보기, 기본 포스터, 이 도구로 만든 홈페이지 주소로 불러오기, ZIP)는 키 없이 됩니다.

**안전 장치**: AI 가 만든 HTML·그림에서 스크립트·외부 주소·이벤트 속성을 지우고, 미리보기는 스크립트를 실행하지 않는 틀(sandbox)에서 보여 주며, 결과 파일에는 외부 접속을 막는 보안 정책(CSP)을 넣습니다. 배색 값은 홈페이지와 같은 규칙(변수 이름·색 형식)으로 걸러 냅니다.

## 4. 저장은 어디에 되나

- 입력한 내용은 **이 브라우저 안에만** 자동 저장됩니다(localStorage). 올린 사진·PDF 는 브라우저의 IndexedDB 에 저장됩니다. 이 도구는 어떤 서버로도 내용을 보내지 않습니다(AI 기능을 쓸 때 고른 AI 서비스는 예외).
- 다른 컴퓨터·다른 브라우저에서는 보이지 않습니다. 옮길 때는 **원본 저장** 파일과 사진 원본(또는 배포용 ZIP)을 가져가 **불러오기** 하세요. 배포용 ZIP 을 불러오면 사진까지 돌아오지만, 이메일은 난독화된 공개본이므로 원본 저장 파일이 더 좋습니다.
- 브라우저의 "인터넷 사용 기록 삭제(사이트 데이터)"를 하면 지워집니다. 중요한 작업 뒤에는 원본 저장을 해 두세요.
- 공용 PC 에서는 다 쓴 뒤 시작하기 → 새로 만들기로 비워 두세요.
