# 웹 도구로 만들기 (설치 없음)

> **주소: https://songh2.github.io/conference-site/**
> 브라우저에서 칸을 채우면 오른쪽에 홈페이지가 바로 보이고, 다 되면 ZIP 을 받아 GitHub 에 올리면 끝입니다.
> 파이썬·AI 도우미·프로그램 설치가 필요 없습니다. 서울대학교 공식 서비스가 아닌 개인 프로젝트입니다.

## 1. 무엇이 되나

| 할 수 있는 것 | 어디서 |
|---|---|
| 한·영 홈페이지 만들기 (행사명, 일시, 장소, 프로그램, 연사·초록·수식, 위원회, 문의처, 공지, 자료, 사진, 후원) | 각 탭 |
| 실시간 미리보기 (PC·휴대폰 폭) | 오른쪽 |
| 서울대 단과대학 배색 17종 | 디자인 |
| 홈페이지 안 사전등록 양식 + 구글 시트 접수 스크립트 | 등록 |
| 인쇄 포스터 4종 (A1~A4, QR 코드) · OpenDesign 브리프 | 포스터 |
| 공문·포스터에서 자동 채우기 (본인 API 키) | 시작하기 |
| 검사, 배포용 ZIP, 원본 저장 | 검사·내려받기 |
| GitHub Pages 올리는 순서 | GitHub에 올리기 |

홈페이지·검사·포스터·등록 스크립트는 저장소의 `scripts/*.py` 를 **브라우저 안에서 그대로 실행**해 만듭니다(Pyodide). 그래서 AI 도우미나 컴퓨터에서 `python3 scripts/build.py` 로 만든 것과 결과가 같습니다(자동 시험으로 확인).

## 2. 처음 쓰기 (10~20분)

1. **Chrome 이나 Edge** 로 위 주소를 엽니다. 처음 한 번은 오른쪽 위가 "◌ 파이썬 엔진 내려받는 중…" 으로 보입니다. 엔진은 약 12MB(압축 전 기준)이고 인터넷 속도에 따라 10초~1분 걸립니다. "● 준비됨" 이 되면 시작합니다. 다음부터는 브라우저에 저장된 사본을 쓰므로 빨라집니다.
2. **시작하기** 에서 고릅니다.
   - 새로 만들기: 빈 양식
   - 예시로 둘러보기: 모든 칸이 채워진 가상 행사 (처음이면 이것부터 보세요)
   - 불러오기: 예전에 보관한 `conference.json`, 또는 이 도구로 받은 ZIP
3. 왼쪽 단계 순서대로 채웁니다. 한국어·영어 칸이 나란히 있고, 영어를 비우면 영어 화면에도 한국어가 나옵니다.
   - **자료에 없는 내용은 비워 두세요.** 비운 칸의 부분은 홈페이지에서 자동으로 숨겨집니다.
   - 사진·PDF 는 각 칸의 **파일 올리기** 로 넣습니다. 사진은 본인 동의를 받은 것, 로고는 사용 권한이 있는 것만.
4. **검사·내려받기** 탭에서 빨간 오류가 없으면 **배포용 ZIP 받기** 를 누릅니다. 노란 경고는 "확인 필요 목록"입니다(대부분 영문이 비었다는 안내).
5. **원본 저장** 도 눌러 `○○-conference.json` 을 학과 공유 폴더 등에 보관하세요. 나중에 고칠 때 이 파일을 불러옵니다. 이 파일에는 이메일이 평문으로 들어 있으니 **공개 저장소에는 올리지 않습니다.**
6. **GitHub에 올리기** 탭의 순서대로 올립니다(처음 한 번 10분). 더 자세한 설명: [GitHub Pages 매뉴얼](manual-github-pages.md).

## 3. 자료에서 자동으로 채우기 (AI, 선택)

공문·포스터(PDF·그림)·한글(HWPX)·워드(DOCX)·텍스트 파일을 올리면 AI 가 읽어 칸을 채웁니다. **본인의 API 키가 필요하고, 사용료는 키를 만든 계정에서 나갑니다.**

| AI 서비스 | 주소(자동 입력) | 키 | 그림(포스터) 읽기 |
|---|---|---|---|
| 팩트챗 (서울대 구성원) | `https://factchat-cloud.mindlogic.ai/v1/gateway` | 마인드로직 API 게이트웨이에서 만든 키 | Claude 계열 모델(`claude-…`)만. 다른 모델은 글자만 |
| OpenAI | `https://api.openai.com/v1` | OpenAI API 키 | 됨 |
| 직접 입력 | OpenAI 호환 주소 | 그 서비스의 키 | 서비스에 따라 다름 |

- **팩트챗 키 만들기**: 마인드로직 공식 문서(docs.mindlogic.ai)에는 "Baze 웹사이트에 로그인 → 왼쪽 아래 버튼 → API Gateway → API 키 생성"으로 안내되어 있습니다. 서울대 계정에서 메뉴 이름이 다를 수 있습니다(이 문서 작성 때 확인하지 못함).
- **모델 고르기**: 키를 넣고 "모델 목록 불러오기"를 누르면 쓸 수 있는 모델이 나옵니다. 그림으로만 된 포스터(글자를 복사할 수 없는 PDF)는 그림을 읽는 모델이 필요합니다. 팩트챗이라면 `claude-…` 모델을 고르세요.
- **채우는 방식**: "자료 내용으로 새로 채우기"(지금 고른 테마·로고·포스터 설정은 그대로 둠) 또는 "지금 비어 있는 칸만 채우기".
- **결과 확인**: 적용하기 전에 요약표와 "확인 필요" 목록이 나옵니다. **AI 는 틀릴 수 있습니다.** 적용한 뒤 각 탭에서 원문과 한 줄씩 대조하세요. 자료에 없는 것은 지어내지 말고 비워 두도록 지시해 두었지만, 결과를 보장하지는 않습니다.
- **개인정보**: 올린 자료는 고른 AI 서비스로 전송됩니다. 참가자 명단·주민등록번호 같은 개인정보 파일은 올리지 마세요.
- **키 보관**: 기본은 이 탭을 닫으면 잊습니다. "이 브라우저에 키 기억"을 켜면 이 컴퓨터의 브라우저에 남으니 **공용 PC 에서는 끄고**, 다 쓰면 "키 지우기"를 누르세요. 키는 고른 AI 서비스 외의 곳으로 보내지 않습니다(이 도구에는 서버가 없습니다).
- 예전 한글 형식(.hwp)은 읽지 못합니다. 한글에서 "다른 이름으로 저장 → PDF 또는 HWPX" 로 저장해 올리세요. PDF 는 앞 8쪽까지, 그림은 12장까지 읽습니다.

## 4. 저장은 어디에 되나

- 입력한 내용은 **이 브라우저 안에만** 자동 저장됩니다(localStorage). 올린 사진·PDF 는 브라우저의 IndexedDB 에 저장됩니다. 이 도구는 어떤 서버로도 내용을 보내지 않습니다(AI 기능을 쓸 때 고른 AI 서비스는 예외).
- 다른 컴퓨터·다른 브라우저에서는 보이지 않습니다. 옮길 때는 **원본 저장** 파일과 사진 원본(또는 배포용 ZIP)을 가져가 **불러오기** 하세요. 배포용 ZIP 을 불러오면 사진까지 돌아오지만, 이메일은 난독화된 공개본이므로 원본 저장 파일이 더 좋습니다.
- 브라우저의 "인터넷 사용 기록 삭제(사이트 데이터)"를 하면 지워집니다. 중요한 작업 뒤에는 원본 저장을 해 두세요.
- 공용 PC 에서는 다 쓴 뒤 시작하기 → 새로 만들기로 비워 두세요.

## 5. 나중에 고칠 때

- **이 도구로**: 불러오기 → 보관한 원본 `conference.json` (사진은 다시 올리기) → 고치기 → 새 배포용 ZIP → GitHub 저장소에서 Add file → Upload files 로 다시 올리기(같은 이름은 덮어써짐).
- **GitHub 에서 바로**: 저장소의 `conference.json` 을 열고 연필(✎) 버튼으로 글자를 고쳐 저장하면 1~2분 뒤 반영됩니다. 이메일은 직접 넣지 말고 [`tools/encode-email.html`](../tools/encode-email.html) 로 만든 `email_enc` 값을 씁니다.

## 6. 문제가 생기면

| 증상 | 해결 |
|---|---|
| "엔진을 불러오지 못했습니다" | 인터넷 연결을 확인하고 "다시 시도". 학교·회사 망에서 `cdn.jsdelivr.net` 이 막혀 있으면 엔진을 받을 수 없습니다(다른 망에서 시도) |
| 미리보기가 비어 있음 | "새로고침" 버튼. 행사명이 비어 있으면 거의 빈 화면이 정상입니다 |
| ZIP 버튼을 눌러도 받아지지 않음 | 검사 탭의 빨간 오류(예: 주소용 이름 없음, 날짜 형식)를 먼저 고칩니다 |
| 사진 칸에 "파일 없음" | 원본 JSON 만 불러오면 사진은 따라오지 않습니다. 다시 "파일 올리기" |
| AI 오류 401 / 403 / 404 / 429 | 키 확인 / 그 키로 쓸 수 없는 모델 / 주소·모델 이름 확인 / 사용 한도·크레딧 확인 |
| AI 가 그림을 안 읽음 | 팩트챗에서는 `claude-…` 모델을 고르세요 |

## 7. 확인한 것과 확인하지 못한 것 (2026-10-27)

- **확인함 (자동 시험)**: 예시 행사로 만든 배포 ZIP 의 `index.html`·공개본 `conference.json` 이 컴퓨터의 `build.py --deploy` 결과와 한 글자도 다르지 않음, 등록 스크립트·포스터 HTML 도 같음, 입력 → 미리보기·자동 저장, 테마 변경, ZIP 다시 불러오기, 휴대폰 폭(390px) 가로 넘침 없음. AI 기능은 **가짜 응답**으로 요청 형식(팩트챗 Claude: Messages, 팩트챗 기타: Chat Completions 글자 전용, OpenAI: Chat Completions + 그림)을 확인했습니다.
- **확인함 (실제 서버)**: 팩트챗·OpenAI 주소가 GitHub Pages 주소에서 보낸 요청에 응답함(브라우저 CORS 허용, 잘못된 키로 401 응답 확인).
- **확인하지 못함**: 실제 키로 팩트챗·OpenAI 를 부른 결과(내용 품질·비용), Safari·모바일 브라우저에서의 엔진 동작, 학교 망의 CDN 차단 여부. 처음 써 보신 분이 결과를 이 문서에 보태 주세요.

## 8. 만드는 사람을 위한 메모

- 화면: `index.html`, `web/main.js`(연결), `web/fields.js`(입력 항목), `web/form.js`(양식 그리기), `web/engine.js`(Pyodide·파일 보관), `web/ai.js`(AI), `web/builder.css`.
- 파이썬 연결: `web/bridge.py` — 새 계산 로직 없이 `scripts/*.py` 를 불러 씁니다.
- `scripts/`·`template/`·`themes/` 를 고치면 **`python3 scripts/make_web_manifest.py`** 로 `web/manifest.json` 을 갱신해 함께 커밋합니다(`selftest.py` 가 확인). `version` 값이 바뀌어 브라우저가 옛 파일을 쓰지 않습니다.
- 외부 라이브러리: Pyodide 0.29.5, pdf.js 5.7.284 (jsDelivr CDN, 버전 고정), segno 1.6.6(QR, `web/vendor/`, BSD-3-Clause).
- 이 웹 도구 파일은 ChatGPT·Claude 용 스킬 묶음(`package_skill.py`)에는 들어가지 않습니다.
