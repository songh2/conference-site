# 배색(테마)과 로고 — 단과대학별 디자인 적용

> 홈페이지의 색·글꼴·모서리 같은 "분위기"는 **테마 프리셋**으로 바꿉니다. 배치(레이아웃)는 모든 사이트가 같습니다.
> 프리셋 하나 = `themes/<id>.json` 파일 하나. `conference.json` 에 `"theme": "<id>"` 한 줄로 적용됩니다.

## 1. 고르는 방법

1. 미리보기 갤러리를 만들어 봅니다(파이썬이 있을 때). 파일 하나로 만들어지며, 화면 아래 막대에서 프리셋을 골라 바로 비교합니다:
   ```bash
   python3 scripts/theme_gallery.py                 # 예시 사이트로
   python3 scripts/theme_gallery.py sites/<slug>    # 내 사이트로
   ```
   `dist/theme-gallery/index.html` 을 더블클릭해 엽니다.
   이미 공개한 사이트라면 주소 끝에 `?theme=snu-science` 처럼 붙여 열어도 그 배색으로 미리 볼 수 있습니다(저장되지 않음).
   AI 도우미에게 "테마 갤러리 만들어 줘"라고 해도 됩니다.
2. 마음에 드는 것의 id 를 `conference.json` 에 적습니다:
   ```json
   "theme": "snu-engineering"
   ```
3. 이미 GitHub 에 올린 사이트라면 `conference.json` 의 이 값만 웹에서 고쳐도 **다시 빌드 없이** 바뀝니다(페이지가 열릴 때 적용).

일부 색만 바꾸고 싶으면:
```json
"theme": { "preset": "slate", "--accent": "#d9a441" }
```
프리셋 없이 직접 지정만 하려면 `"theme": { "--primary": "#0b3d91", "--accent": "#c8a24a" }`.

**근거 구분**
- **공식 색 기반**: 공식 UI 안내에 적힌 수치를 썼습니다. `snu` 는 서울대학교 UI 가이드(identity.snu.ac.kr, "전용색상")의 SNU Blue `#0f0f70`(Pantone 2748C, RGB 15/15/112)·SNU Beige `#dcdab2`(RGB 220/218/178), `snu-engineering` 은 공과대학 UI 페이지의 SENG Orange `#f78f1e`·SENG Gray `#818085` 입니다.
- **홈페이지 추출(공식 아님)**: 각 대학 홈페이지를 실제 브라우저(1366×900)로 열어, 화면에 쓰인 배경·글자·테두리 색을 면적·글자 수로 집계해 대표색을 골랐습니다. 그 대학이 정한 공식 색이라는 뜻이 **아닙니다**. 홈페이지가 바뀌면 값도 달라질 수 있습니다.
- 강조색을 섞어 만든 연한 색(`--accent-soft`)·마우스 올림 색(`--accent-hover`)처럼 **계산으로 만든 값**은 각 파일의 `source` 에 "파생값"으로 적어 두었습니다.
- 모든 프리셋은 글자 대비 기준(일반 글자 4.5:1, 키보드 초점 테두리 3:1, WCAG)을 자동 시험(`scripts/selftest.py`)으로 확인했습니다.

**알아 두면 좋은 점**
- 사회과학대학·사범대학·생활과학대학·약학대학·수의과대학·자유전공학부·첨단융합학부 홈페이지는 같은 학내 공통 틀(상단 띠 `#272727`)을 쓰고, 여러 곳이 SNU Blue `#0f0f70` 을 그대로 씁니다. 그래서 사회대·사범대·약학대 프리셋은 서로 비슷합니다(강조색으로 구분).
- 서울대학교 UI 가이드는 **교내기관 시그니처(로고)** 색을 SNU Blue 원칙(상황에 따라 SNU Gray·검정·흰색)으로 정하고, 단과대학·학과는 독자 심볼 없이 교내기관 기본 시그니처를 쓰도록 권장하며, 지정되지 않은 색을 시그니처에 쓰는 것을 금지합니다. 이 프리셋은 **홈페이지 배색**에만 적용되고 로고 색은 바꾸지 않습니다. 로고는 `logo` 항목에 학교가 제공한 시그니처 파일을 그대로 넣으세요(4절).
- 서울대 지정 서체는 윤고딕(국문)·Univers(영문)입니다. 학교가 받은 라이선스는 교내 PC 설치용이므로 이 템플릿에 글꼴 파일을 넣지 않았습니다. 웹폰트로 쓰려면 라이선스를 따로 확인하세요(5절).

### 다시 확인하는 방법
홈페이지 색은 대학이 개편하면 바뀝니다. 다시 확인하려면 AI 도우미에게 "브라우저로 OO대학 홈페이지 색을 다시 읽어서 `themes/snu-xxx.json` 을 갱신해 줘"라고 요청하세요(브라우저 도구가 있는 환경에서만 가능). 공식 수치를 구했다면 `status` 를 `official` 로 바꾸고 `source` 에 문서 주소를 적습니다.

## 3. 단과대학 프리셋 추가하기 (누구나)

1. 색상 값 구하기 — 셋 중 하나:
   - 단과대학 홈페이지의 **UI/CI 안내 페이지**(예: 공과대학 `about/engineering/UI`)에 RGB·HEX 가 적혀 있는지 확인
   - 대학 홍보·기획 담당 부서에 "홈페이지용 대표색 HEX 값"을 문의
   - 둘 다 안 되면 홈페이지 화면에서 읽은 값을 쓰되 **상태를 `extracted`** 로 적고 `source` 에 주소·날짜·측정 방법을 남김
2. `themes/_template.json` 을 복사해 `themes/<id>.json` 으로 저장 (id 는 소문자·숫자·하이픈, 파일 이름과 같게. 예: `snu-business`)
3. `name`, `status`, `group`(`snu` 또는 `generic`), `source`(어디서, 언제 확인했는지), `note`(어느 값이 공식이고 어느 값이 임의인지), `vars` 를 채웁니다.
4. `python3 scripts/theme_gallery.py` 로 보면서 조정하고, `python3 scripts/selftest.py` 로 글자 대비를 확인합니다(읽기 어려운 조합이 있으면 FAIL 과 함께 어느 항목인지 알려 줍니다).
5. 저장소에 올립니다(Pull request 환영). 그 뒤부터 모든 사용자가 `"theme": "snu-business"` 로 쓸 수 있습니다.

### 바꿀 수 있는 변수

| 변수 | 쓰이는 곳 | 기본값 |
|---|---|---|
| `--primary` | 표 머리, 버튼, 링크, 언어 버튼 | `#173a5e` |
| `--primary-deep` | 제목 글자, 대표 영역(히어로) 시작색, 바닥글 | `#0f2a46` |
| `--hero-end` | 히어로 그라데이션 끝색 | `#2b5a86` |
| `--accent` / `--accent-hover` / `--accent-ink` | 강조 버튼(사전등록) 배경 / 마우스 올렸을 때 / 글자색 | 금색 / 밝은 금색 / 진갈색 |
| `--accent-soft` | 강조 연한 배경(선택된 항목, 배지) | `#f6ecd8` |
| `--ink`, `--ink-soft`, `--muted` | 본문 글자 / 보조 글자 / 흐린 글자 | 짙은 남회색 계열 |
| `--bg`, `--surface`, `--soft`, `--line` | 페이지 배경 / 카드 배경 / 연한 구역 배경 / 테두리 | 미색 계열 |
| `--font-head`, `--font-body` | 제목 글꼴 / 본문 글꼴 (글꼴 이름 목록) | 명조 / 고딕 |
| `--radius`, `--radius-sm` | 카드·입력칸 모서리 둥글기 | `14px` / `8px` |
| `--focus` | 키보드 초점 테두리(밝은 바탕 위) | `--primary` 와 같음 |
| `--accent-line` | 공지 왼쪽 강조선 | `--accent` 와 같음 (강조색이 흰색이면 따로 지정) |

값에는 색(`#rrggbb`, `rgb(...)`), 글꼴 목록, `px` 만 쓸 수 있습니다. `url(`, `;`, `{` 같은 것은 보안상 거부됩니다.

## 4. 로고 넣기

```json
"logo": { "src": "assets/logo.svg", "alt": { "ko": "서울대학교 공과대학", "en": "SNU College of Engineering" } }
```
- 상단바 왼쪽, 행사 이름 앞에 높이 34px 로 표시됩니다. 행사 이름 글자를 숨기고 로고만 보이려면 `"hide_text": true` 를 추가합니다(글자는 화면 낭독기에는 남습니다).
- **파일은 사용 권한을 확인한 것만** 넣습니다. 이 템플릿에는 어떤 기관의 로고도 들어 있지 않습니다. 서울대학교 엠블럼은 등록 상표이며 사용 규정이 있습니다(`docs/security.md` 3절).
- SVG 또는 가로로 긴 PNG(높이 100px 내외로 줄인 것) 권장. 공개 저장소에 올라가므로 고해상도 원본은 넣지 않습니다.

## 5. 글꼴에 관해

- 기본 글꼴은 Google Fonts 의 Noto Sans KR(본문)·Noto Serif KR(제목)입니다. 기관 지정 글꼴이 있으면 `--font-head`/`--font-body` 에 이름을 적되, 웹폰트 파일을 저장소에 넣으려면 그 글꼴의 **배포 라이선스**를 확인해야 합니다. 기관이 자체 제작·배포하는 글꼴이라도 "홈페이지 삽입 허용" 여부는 다릅니다.
- 애플 기기용 시스템 글꼴 등은 사용자의 기기에 있을 때만 보이므로, 목록 뒤에 항상 대체 글꼴(`"Noto Sans KR", sans-serif`)을 둡니다.

## 6. 디자인을 통일하고 싶을 때 (여러 행사)

- 부서에서 프리셋 하나를 정하고(예: `snu-engineering`), 새 사이트의 `conference.json` 에 그 id 를 넣도록 안내하면 됩니다. `template/conference.skeleton.json` 의 `"theme"` 기본값을 바꾸면 그 저장소로 만드는 모든 새 사이트가 그 프리셋을 씁니다.
- 레이아웃 자체(상단바 형태, 섹션 순서)를 기관 홈페이지와 맞추는 것은 `template/style.css` 를 고치는 일이라 프리셋으로는 안 됩니다. 필요하면 저장소에 제안(issue)을 남겨 주세요.
