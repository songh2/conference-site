# 자주 묻는 질문

**Q. 이 저장소(스킬)와 행사 홈페이지 저장소는 어떻게 다른가요?**
둘은 별개입니다.
- **이 저장소(`conference-site`)** = 틀(템플릿)·스크립트·설명서. 모두가 공유하며, 여기에 자기 행사 내용을 넣지 않습니다.
- **행사 저장소(예: `ntc2027`)** = 행사 하나의 홈페이지 파일(`index.html`, `conference.json`, `assets/`). 행사마다 하나씩 만들어 GitHub Pages 로 공개합니다.
AI 도우미는 이 저장소의 `SKILL.md` 를 읽고, 결과 파일을 행사 저장소에 올리도록 만들어 줍니다.

**Q. 발표자의 발표자료·초록·논문을 받아서 홈페이지에 넣는 기능이 있나요?**
있습니다. 세 가지 경로 모두 이미 구현되어 있습니다.
1. 구글폼으로 받기 → 응답 CSV → `scripts/import_speakers.py` (문항 템플릿·절차: `references/speaker-submission.md`)
2. 발표자가 보낸 메일·PDF 를 AI 도우미에게 **첨부**하고 "홍길동 발표자료로 연결해 줘" → `speakers[].slides`·`abstract`·`title` 이 채워지고 PDF 는 `assets/slides/<id>.pdf` 로 저장됩니다.
3. `conference.json` 을 직접 편집 (`references/schema.md` → speakers)
논문·보충자료도 `slides` 배열에 `{"label": {"ko": "논문", "en": "Paper"}, "url": "..."}` 로 여러 개 넣을 수 있습니다.
반영 결과는 **행사 저장소**(PDF 와 `conference.json`)에 올려야 홈페이지에 보입니다. 이 스킬 저장소에는 아무것도 추가할 필요가 없습니다.

**Q. ChatGPT 에 자료를 첨부해서 요청하면 되나요?**
됩니다. 단, ChatGPT 가 파일(PDF)을 저장소에 올려 주지는 못하므로 PDF 는 본인이 행사 저장소의 `assets/slides/` 에 올리고, ChatGPT 가 고쳐 준 `conference.json` 을 교체합니다. → `docs/manual-chatgpt.md`

**Q. 홈페이지 주소에서 내 아이디를 뺄 수 있나요?**
`github.io` 주소는 `<계정 또는 조직>.github.io/<저장소>/` 형식이 고정입니다. 개인 아이디 대신 **조직 이름**을 쓰거나(권장), 사용자 도메인을 붙입니다. → `docs/manual-github-pages.md` 8절

**Q. 등록 양식은 꼭 구글 시트여야 하나요?**
정적 홈페이지에는 서버가 없어서, 무료·무설치로 접수를 받으려면 구글 Apps Script 가 가장 간단합니다. 구글을 쓸 수 없으면 `registration.form_url` 에 다른 설문 서비스 링크를 넣는 방식(링크/삽입)으로 돌아갈 수 있습니다.

**Q. 참가자 명단도 공개되나요?**
이름·소속만, 등록 시 "명단 게시 동의"를 한 사람만 보입니다. 이메일은 서버가 돌려주지 않습니다.

**Q. 디자인을 우리 단과대학 색으로 바꾸고 싶어요.**
`"theme"` 값 하나로 바꿉니다. 서울대학교 공통(`snu`)과 16개 단과대학·학부 프리셋(`snu-science` 등)이 들어 있습니다. 대부분은 각 대학 홈페이지 화면에서 읽은 색이라 공식 색은 아닙니다. 다른 기관은 `themes/_template.json` 을 복사해 추가합니다. → `docs/themes.md`

**Q. 행사가 끝나면 지워야 하나요?**
지우지 마세요. 참석 증빙·정산 증빙 주소로 계속 쓰입니다. 단, 구글 시트의 개인정보는 보유 기간이 지나면 삭제합니다.

**Q. 한 행사를 여러 페이지로 나눌 수 있나요?**
현재는 한 페이지 스크롤 + 상단 메뉴 점프 방식입니다. 초록이 많으면 "초록 보기" 접기로 길이를 줄입니다. 다중 페이지는 개선 과제입니다.

**Q. 인쇄하면 어떻게 나오나요?**
메뉴·버튼·지도·등록 양식은 빠지고 제목·일시·행사장·프로그램·초록(자동 펼침)·위원·명단·문의처가 흑백 문서로 나옵니다.

**Q. 이 저장소는 서울대학교 공식 서비스인가요?**
아닙니다. 수리과학부 행정 담당자가 반복 업무를 줄이려고 만들어 구성원 누구나 쓰도록 공개한 개인 프로젝트입니다(MIT 라이선스). 공식 로고·색상 사용은 각 기관 규정을 따르세요.
