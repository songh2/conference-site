# 사전등록 폼 템플릿 (구글폼)

> **먼저 보세요 — 홈페이지 안에서 직접 등록받는 방식(권장)**: 이름·소속·참석 구분·이메일만 필요하면 구글폼 대신
> 홈페이지에 등록 양식을 넣고 응답을 구글 시트에 바로 쌓을 수 있다. 설정 순서는 `references/registration-sheet.md`.
> 이 문서의 구글폼 방식은 문항이 많거나(식사·발표 희망·여비 지원 등) 구글폼 기능(파일 업로드, 응답 수정 링크 등)이 필요할 때 쓴다.
> 두 방식은 함께 쓸 수도 있다(`endpoint` 와 `form_url` 을 모두 넣으면 양식 아래에 "작동하지 않으면 구글 폼으로" 링크가 붙는다).

홈페이지는 정적 파일이라 등록 데이터를 직접 받을 수 없다. 사전등록은 **구글폼**으로 받고 그 링크를
`registration.form_url` 에 넣는다. 응답은 자동으로 구글 시트에 쌓이므로 집계가 쉽다.

## 만들기 (학교 Google Workspace 계정 권장)
1. forms.google.com → 새 양식 → 제목: "<행사명> 사전등록 / Registration"
2. 설정(톱니) → **응답**: "이메일 주소 수집" 켬, "응답 횟수 1회로 제한"은 외부인 참가가 많으면 끄기(학교 계정 로그인이 필요해짐)
3. 설정 → **프레젠테이션**: 확인 메시지에 "등록해 주셔서 감사합니다. 문의: office@example.org" 입력
4. 응답 탭 → 시트 아이콘 → "새 스프레드시트 만들기" (집계용)
5. **보내기 → 링크** 의 URL 복사 → `conference.json` 의 `registration.form_url`
   - 페이지 안에 폼을 넣고 싶으면 **보내기 → `< >`** 의 `src="..."` 주소를 쓰고 `"embed": true`
6. 마감일에는 폼의 "응답 받기" 를 끈다. 홈페이지는 `registration.deadline` 을 지나면 자동으로 "마감" 표시

## 권장 문항 (한/영 병기)

| 순서 | 문항 (한국어 / English) | 유형 | 비고 |
|:---:|---|---|---|
| 1 | 성명 / Full name | 단답 | 필수 |
| 2 | 영문 성명 / Name in English (optional) | 단답 | 홈페이지 영어 화면 명단용 (없으면 1번이 그대로 표시) |
| 3 | 소속 / Affiliation | 단답 | 필수 |
| 4 | 영문 소속 / Affiliation in English (optional) | 단답 | 영어 화면 명단용 |
| 5 | 직위 / Position (교수, 박사후연구원, 대학원생, 기타) | 객관식 | 식사·지원금 구분용 |
| 6 | 이메일 / Email | 설정 → "이메일 주소 수집" 또는 단답 | 필수. 중복 응답 판별 기준 |
| 7 | 참석 일자 / Days attending (2/10 사전행사, 2/11, 2/12) | 체크박스 | **점심 쿠폰·케이터링 인원 산출** |
| 8 | 뱅큇 참석 / Banquet attendance (2/11 저녁) | 객관식 | 케이터링 예약 |
| 9 | 식사 제한 사항 / Dietary restrictions | 단답 | 선택 |
| 10 | 발표 희망 / Would you like to give a talk? (예/아니오, 제목) | 객관식 + 단답 | 프로그램 위원회 전달 |
| 11 | 여비 지원 신청 / Travel support request | 객관식 | 예산 범위 확인 후 포함 |
| 12 | **참가자 명단(이름·소속) 홈페이지 게시 동의 / Consent to be listed (name and affiliation) on the website** | 객관식 (예 / 아니오) | **홈페이지 참가자 명단은 "예"인 분만 표시** |
| 13 | 기타 요청 / Other requests | 장문 | 선택 |

- 문항 7·8 이 케이터링 예약(마감 D-23 전후)의 근거가 되므로 필수로 둔다.
- 문항 12 의 제목에 "명단 게시" 또는 "동의"가 들어 있어야 `import_participants.py` 가 동의 열을 자동 인식한다.
- 개인정보 수집·이용 동의 문구를 첫 섹션에 넣는다(학교 양식 참고).

## 홈페이지 참가자 명단에 반영하기

홈페이지의 "참가자 명단" 섹션에는 **이름과 소속만** 올라간다(게시에 동의한 사람만). 두 가지 방법이 있다.

**방법 1 — 주기적으로 반영 (기본, 권장)**
```bash
# 응답 시트 → 파일 → 다운로드 → CSV
python3 scripts/import_participants.py sites/<slug> ~/Downloads/responses.csv --dry-run   # 미리 보기
python3 scripts/import_participants.py sites/<slug> ~/Downloads/responses.csv             # 반영 (이름순은 --sort)
# 그 다음 build.py, 또는 배포 저장소의 conference.json 만 교체
```
- 명단은 시트 전체로 매번 다시 만들어지므로, 취소·수정은 시트에서 하면 된다. 같은 사람이 다시 응답하면 마지막 응답이 쓰인다.
- AI 도우미에게 "등록 시트를 읽어서 ntc2027 참가자 명단을 갱신해 줘" 라고 해도 된다(구글 시트 커넥터 연결 시). 반영 주기는 주 1회 정도면 충분하고, 마감 후 한 번 더 한다.

**방법 2 — 시트에서 자동으로 읽기 (선택)**
1. 응답 시트에 **새 탭**을 만들고 `=QUERY(폼응답1!A:Z, "select C, E where L = '예 / Yes'")` 처럼 이름·소속(동의자만) 열만 가져오는 수식을 넣는다. (열 문자는 실제 시트에 맞춘다. 첫 행에 "성명", "소속" 제목이 오게 한다.)
2. 파일 → 공유 → **웹에 게시** → 그 탭만 선택 → 형식 **CSV** → 게시 → 주소 복사.
3. `conference.json` 의 `"participants_url"` 에 붙여 넣는다. 홈페이지가 열릴 때마다 이 주소를 읽어 명단을 표시하고, 읽지 못하면 `participants` 에 적힌 명단을 보여 준다.

주의: 방법 2 는 **게시한 탭의 내용이 누구나 볼 수 있는 공개 주소**가 된다. 반드시 이름·소속만 있는 탭을 게시하고, 원본 응답 탭(이메일·연락처 포함)은 게시하지 않는다. 자동 반영이 꼭 필요하지 않으면 방법 1 이 더 안전하다.

## 집계 (예: 2027-01-05 "사전등록 결과 취합" 마감)
구글 시트에서:
- 총 인원: `=COUNTA(C2:C)` (성명 열 — 실제 열 문자는 시트에 맞춘다)
- 날짜별 인원: `=COUNTIF(I2:I, "*2/11*")` (참석 일자 열에 포함된 날짜 세기)
- 뱅큇 인원: `=COUNTIF(J2:J, "예")`
결과를 "예상 참석 인원" 으로 정리해 조직위원회에 보고한다.

## 참가자 명단은 홈페이지(공개 저장소)에 올리지 않는다
명단·연락처는 구글 시트에만 두고, 홈페이지에는 집계 숫자조차 올릴 필요가 없다.
