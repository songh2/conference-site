# 학회 준비 체크리스트 (마감일 역산표)

아래 간격은 "정기 정수론 학회 2027"(본행사 2027-02-11) 준비 일정에서 뽑은 것이다.
다른 행사에서는 행사일(D)에서 같은 간격으로 역산해 초안을 만들고, 조직위원회와 조정한다.

## 사전 준비

| 시점 | 업무 | 산출물 | 이 스킬과의 관계 |
|---|---|---|---|
| D-90 (≈3개월 전) | 홈페이지 제작 + 사전등록 폼 생성·탑재 | 공개 URL | `build.py` → GitHub Pages 배포, `registration-sheet.md`(홈페이지 안 등록 양식) 또는 `registration-form.md`(구글폼) |
| D-37 | 사전등록 결과 취합, 예상 참석 인원 파악 | 인원표(총원·일자별·뱅큇) | 구글 시트 집계 (`registration-sheet.md` 방식이면 시트의 `집계` 탭) |
| D-32 | 행사 중 업무 담당자 섭외 | 담당자 명단(등록, 사진, 현수막, 케이터링, 민원) | — |
| D-27 | 포스터 제작 | PDF | 완성 후 `downloads` 에 추가 |
| D-22 | 뱅큇·점심 쿠폰·다과 케이터링 예약 | 예약 확정서 | 인원은 등록 집계 기준 |
| D-7 | 사전등록자 명찰·현수막 제작 | 명찰, 현수막 | 명찰 명단은 시트에서 추출 |

예산 집행처(예: 기초연구실 과제)가 정해져 있으면 포스터·현수막 발주 전에 담당자와 협의한다.

## 행사 당일

- 등록 데스크 운영, 점심 쿠폰 배부
- 단체 사진 촬영 (→ 행사 후 `gallery` 에 게시)
- 현수막 거치
- 케이터링 수발·관리
- 참가자 돌발 민원 대응 (명찰 재발급, 좌석, 영수증 등)

## 행사 후 (홈페이지를 기록용으로 전환)

| 업무 | 홈페이지 반영 |
|---|---|
| 단체사진 게시 | `gallery` |
| 발표자료(허락받은 것) 게시 | `speakers[].slides` 또는 `downloads` |
| 최종 프로그램 확정본 | `program` 의 `tentative` 를 모두 `false` 로 |
| 여비 정산 | 참가자가 홈페이지 URL 과 프로그램을 증빙으로 제출 → 사이트를 삭제하지 말 것 |
| `updated` 날짜 갱신 | 푸터 "최종 수정" |
