# 발표자 정보·발표자료 수집과 홈페이지 연동

강연자가 정해지면 (1) 강연 제목·초록을 받아 프로그램 표와 "강연 및 초록" 섹션에 올리고,
(2) 행사 전후에 발표자료(PDF)를 받아 각 강연에 링크한다. 손으로 옮겨 적지 않도록
**구글폼 → CSV → `scripts/import_speakers.py`** 흐름을 쓴다.

## 홈페이지에서 어떻게 보이나
- `speakers[]` 의 각 발표자는 "강연 및 초록" 섹션에 카드로 표시된다: 이름(홈페이지 링크) · 소속 · 강연 제목 · [초록 보기] 접기 · 발표자료 링크 · 이메일 아이콘(확인 코드 입력 후 주소 표시, `schema.md` → 이메일 보호).
- 프로그램 표의 항목에 `"speaker_id": "<발표자 id>"` 를 넣으면, 그 줄의 제목이 **강연 제목으로 바뀌고** 발표자 이름을 누르면 초록 카드로 이동한다. 제목이 아직 없으면 "강연" 같은 원래 제목이 유지되고 카드에는 "강연 제목 추후 공지"가 표시된다.
- 초록·제목에 `$...$`, `$$...$$`, `\(...\)` 로 쓴 수식은 자동으로 렌더링된다(KaTeX, 수식이 있을 때만 로드). 문장 안에 달러 기호를 글자로 써야 하면 `\$` 로 쓴다.

## 1. 발표자 제출 폼 만들기 (구글폼)

학교 Google Workspace 계정으로 forms.google.com → 새 양식. 제목: "<행사명> 발표자 정보 제출 / Speaker information".

| 순서 | 문항 (한국어 / English) | 유형 | 비고 |
|:---:|---|---|---|
| 1 | 이메일 주소 | 설정 → "이메일 주소 수집" 켬 | 기존 발표자와 맞출 때 기준이 됨 |
| 2 | 성명 / Full name | 단답, 필수 | 한글 성명(외국인은 영문) |
| 3 | 영문 성명 / Name in English | 단답 | 영어 화면용. 본인 표기를 그대로 사용 |
| 4 | 소속 / Affiliation | 단답, 필수 | |
| 5 | 강연 제목 / Talk title | 단답, 필수 | 수식은 `$...$` |
| 6 | 초록 / Abstract | 장문 | 문단은 빈 줄로 구분 |
| 7 | 발표자료 (PDF) / Slides | **파일 업로드** | 아래 주의 참고 |
| 8 | 홈페이지 / Homepage | 단답 (URL) | 선택 |
| 9 | 발표자료 홈페이지 게시 동의 / Consent to post slides | 객관식 (예 / 아니오) | "아니오"면 import 시 자료를 올리지 않음 |

문항 제목을 위 표처럼 **한/영 병기**로 두면 `import_speakers.py` 가 열을 자동으로 인식한다.
다른 이름을 쓰면 `--map` 으로 지정한다.

### 파일 업로드 문항 주의
- 구글폼의 파일 업로드 문항은 응답자가 **구글 계정으로 로그인**해야 쓸 수 있고, 학교 Workspace 양식은 설정에 따라 **학교 계정만** 허용될 수 있다(외부 연사가 못 올릴 수 있음). 양식 설정 → "응답" 에서 조직 외부 응답 허용 여부를 확인하고, 안 되면 **이메일로 PDF 를 받아** 담당자가 `assets/slides/` 에 넣는다.
- 업로드된 파일은 담당자 드라이브의 자동 생성 폴더에 **비공개**로 저장된다. 홈페이지에 링크하려면 둘 중 하나:
  1. (권장) PDF 를 내려받아 `sites/<slug>/assets/slides/<id>.pdf` 로 저장하고 `slides` 에 그 경로를 적는다 — 행사가 끝난 뒤에도 드라이브 정리와 무관하게 남는다.
  2. 드라이브에서 파일 공유를 "링크가 있는 모든 사용자 → 뷰어"로 바꾸고 드라이브 링크를 그대로 둔다.

### 받는 시점
| 시점 | 받을 것 | 쓰임 |
|---|---|---|
| 포스터 제작 전 (예: D-30) | 성명·소속·제목·초록 | 포스터, 프로그램 표, 초록 섹션 |
| 행사 직전~직후 | 발표자료 PDF, 게시 동의 | 사후 기록용 링크 |
같은 폼을 두 번 보내도 되고(2차엔 7·9번만), 두 번째 응답은 이메일로 같은 발표자에 합쳐진다.

## 2. 응답을 홈페이지에 반영하기

```bash
# 구글폼 → 응답 탭 → 시트 아이콘 → 시트에서 파일 → 다운로드 → CSV
python3 scripts/import_speakers.py sites/<slug> ~/Downloads/responses.csv --dry-run   # 미리 보기
python3 scripts/import_speakers.py sites/<slug> ~/Downloads/responses.csv             # 반영
```
- 출력에 발표자별 `id` 가 나온다. 프로그램 표에서 해당 강연 항목에 `"speaker_id": "<id>"` 를 넣는다.
- 드라이브 링크로 들어온 자료는 목록으로 알려 주므로 위 "파일 업로드 문항 주의"대로 처리한다.
- 그 다음 `validate.py` → `build.py` 로 다시 만들고 올린다.

AI 도우미에게 시키는 경우: 응답 시트(구글 시트 커넥터를 연결했다면 시트 자체, 아니면 CSV 파일)를 주고
"이 응답을 ntc2027 발표자 명단에 반영하고 2/11 14:00 강연에 연결해 줘" 라고 하면 위 절차를 대신한다.

## 3. 손으로 직접 적을 때의 형식
```json
"speakers": [
  {
    "id": "gildong-hong",
    "name": { "ko": "홍길동", "en": "Gildong Hong" },
    "affiliation": { "ko": "예시대학교", "en": "Example University" },
    "title": { "ko": "On the rank of $J_0(N)(\\mathbb{Q})$", "en": "On the rank of $J_0(N)(\\mathbb{Q})$" },
    "abstract": { "ko": "…", "en": "…" },
    "slides": [ { "label": { "ko": "발표자료 (PDF)", "en": "Slides (PDF)" }, "url": "assets/slides/gildong-hong.pdf" } ],
    "url": "https://example.org/~gildong",
    "email": "gildong@example.org"
  }
]
```
`slides` 는 문자열 하나(`"assets/slides/x.pdf"`)로 써도 되고, 여러 파일이면 위처럼 배열로 쓴다.
(위 예시는 형식 설명용 가상 데이터다.)
