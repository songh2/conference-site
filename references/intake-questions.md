# 사용자에게 받을 정보

홈페이지 하나를 만들려면 아래 **필수 7가지**가 있어야 한다. 사용자가 보낸 이메일·공문·메모에서
먼저 추출하고, 빠진 것만 한 번에 묶어 질문한다.

## 필수

| # | 항목 | conference.json 위치 | 질문 예시 |
|---|------|----------------------|-----------|
| 1 | 행사명 (한/영) | `title`, `short_title` | "행사의 공식 영문 명칭이 있나요? 없으면 임시 번역으로 넣고 표시해 두겠습니다." |
| 2 | 기간과 시작·종료 시각 | `dates` | "며칠부터 며칠까지, 첫날 시작 시각과 마지막 날 종료 시각은요?" |
| 3 | 장소 (건물·호실·주소) | `venue` | "건물 번호/이름과 강의실 호수, 지도 링크가 있으면 알려 주세요." |
| 4 | 조직위원·프로그램위원 (이름·소속) | `committees` | "위원 명단과 소속, 가능하면 본인 홈페이지 링크와 게시해도 되는 이메일을 주세요(영문 표기 확인용·링크용)." |
| 5 | 일정 (날짜별 시간표) | `program` | "날짜별로 시간, 항목(등록/강연/휴식/식사/만찬) 순서를 알려 주세요. 미정인 것은 '미정'이라고 적어 주세요." |
| 6 | 등록 방법 (폼 링크, 마감일, 등록비) | `registration` | "사전등록은 어떻게 받으실 건가요? (a) 홈페이지에서 직접 입력 → 구글 시트, (b) 구글폼 링크. (a)라면 참석 구분(예: 사전행사 포함 전체 / 본 행사만 / 일자별)은 어떻게 나누실지, 마감일과 등록비는요?" |
| 7 | 문의처 (담당자 이름·이메일) | `contact` | "홈페이지에 적을 문의 담당자와 이메일은요?" |

## 선택 (없으면 섹션이 자동으로 숨겨짐)

| 항목 | 위치 | 비고 |
|------|------|------|
| 대표 사진 | `hero.image` (`assets/hero.jpg`) | 가로 1600px 이상 권장, 2MB 이하. 없으면 기본 그라데이션 배경 |
| 소개글 | `about` | 공식 문안이 없으면 비운다 (지어내지 않는다) |
| 연사·초록·발표자료 | `speakers`, `program[].items[].speaker_id` | 구글폼으로 받아 `import_speakers.py` 로 반영 → `references/speaker-submission.md` |
| 사전행사·특별세션 | `program[].tentative`, `note` | 미정이면 tentative 로 |
| 숙박·교통 안내 | `accommodation`, `venue.directions` | |
| 행사장 지도 | `venue.lat/lng` | "행사장 좌표(구글 지도에서 건물 우클릭 시 나오는 숫자)를 알려 주시면 지도를 넣습니다." |
| 참가자 명단 | `participants` | 등록폼에 "명단 게시 동의" 문항을 넣고 응답을 `import_participants.py` 로 반영 |
| 후원기관 로고 | `sponsors` | 로고 파일은 `assets/` 에 |
| 공지 | `notices` | 날짜 + 한 줄 |
| 자료(포스터·프로그램북) | `downloads` | PDF 는 `assets/` 에 |
| 단체사진 | `gallery` | 행사 후 추가 |
| 주최·주관 | `host` | |
| 색상 테마 | `theme` | 예: `{"--primary": "#0b3d91", "--accent": "#c8a24a"}` |

## 질문할 때 유의점
- 사용자는 행정 담당자인 경우가 많다. 전문 용어(JSON, 빌드, 슬러그) 대신 "내용 파일", "홈페이지 생성", "주소 이름" 처럼 풀어서 말한다.
- 영문 표기처럼 **사용자가 모를 수 있는 정보**는 "확인 후 알려 주셔도 됩니다. 그동안 한글로 표시됩니다." 라고 안심시킨다.
- 마감일이 촉박한 경우(예: 홈페이지 제출 마감이 3주 뒤) 필수 7가지만으로 먼저 만들고, 선택 항목은 2차 수정으로 미룬다.
