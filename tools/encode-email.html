이메일 주소 보호값(email_enc) 만들기

이 페이지는 컴퓨터에서 바로 열어도 동작하며, 입력한 내용은 어디에도 전송되지 않습니다.
용도: build.py(파이썬)를 쓸 수 없을 때, GitHub 웹 화면에서 conference.json 을 직접 고치면서 위원·발표자·문의처의 이메일을 넣을 때 씁니다. 평문 "email": "..." 대신 아래에서 만든 값을 "email_enc": "v1:..." 로 적으면 방문자가 확인 코드를 입력해야만 주소가 보입니다.
주의: 이것은 암호화가 아니라 자동 수집기를 피하는 난독화입니다. 페이지 코드를 읽으면 되돌릴 수 있습니다.
